This upgrade will:
Change ice data input from BVT ice desk to USNIC ice analysis

The changes in the workflow are listed as:
Addition of new fix files for the new ice data
Omission of old ice fix files
ww3_prep tmpl file changes to account for the new ice
Modification of prep and ush scripts to work with the new format
Changes in dcom path 
Version update
And some cosmetic changes for gitignore

IMPLEMENTATION INSTRUCTIONS ON WCOSS2

Go to your emc/couple/noscrub/$USER directory
 cd <topdir>
 git clone --branch feature/v2.0.7  https://github.com/NOAA-EMC/glwu.git glwu.v2.0.7
 cd glwu.v2.0.7
 git submodule update --init --recursive

 cd sorc
 >> ./get_externals.sh
 >>./make.all.sh >& glwu.compile.log
 An exec/ folder should be created in the main directory after this step

  ***VERY IMPORTANT*** DELETE any wave_glwu*.moddef.* files in the fix directory,
    these should be generated when the system is run for the first time.
